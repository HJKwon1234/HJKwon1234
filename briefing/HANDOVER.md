## 2. 핵심 교훈

**① 확인 후 진입이 3주 폭락 내내 승리했다**
삼성 296,000(7/10) → 274,000(7/22) → 271,000(7/23) 을 모두 추격 회피하고
248,500 · 242,500 에서 확보했다. 이것이 `2-3_확인후진입` 의 근거다.

**② 매수의 인내 ≠ 매도의 인내**
매수에서 기다림은 무기였으나, 매도에서 같은 기다림은 반납이 된다.
하나마이크론 +50% → +17%, 데스티니·두산로보 익절 미실행 -250K.
이것이 `2-5_익절실행` 의 "트리거 도달 시 즉시 실행" 근거다.

**③ 무레버리지가 생존의 전부였다**
마진콜 강제청산이 폭락을 증폭시킨 국면에서 유일한 방패였다.
"계좌 -99.8%" 사례가 속출했으나 신용·미수가 없어 강제청산과 무관했다.

**④ 분산이 실제로 작동했다**
국내 -5% 국면에 SCHD +19%, JEPI, 배당 코어가 방어했다.
SKT(통신)가 반도체 폭락 때 +110%까지 오르며 완충했다.

**⑤ 10% 기계적 손절을 거부한 것이 옳았다**
유튜브 다수가 권했으나 적용했다면 7월 바닥에서 전량 손절 후 8월 반등을 통째로 놓쳤을 것이다.

## 3. 데이터 신뢰도 — 반복 확인된 오류 유형

### 유튜브 팩트체크 43건에서 반복된 오류

- 개인 수급 방향 오류 (매수/매도 반대로)
- 지수 자릿수 오기 (2,796 등)
- 목표가 "상향"과 "유지" 혼동
- "물리법칙" 류 저점 확신
- 10% 기계적 손절 권고 (시스템과 충돌 → 거부)
- 집중투자 권고 (분산 원칙과 충돌 → 거부)

**→ 수치는 반드시 재검증 후 인용한다.**

### 증권사 앱 표시 오류

상단 일간 수익률이 ±30% 상한을 초과하거나 실제와 반대로 표시되는 경우가 잦다.
**개별 종목 손익 금액이 정확하다.**

### 웹 검색의 구조적 한계 (2026-08-11 확인)

| 항목 | 신뢰도 |
|---|---|
| 지수, 수급, 실적 발표일, 기업 이벤트 | 높음 — 널리 보도됨 |
| 환율 | 중간 — 출처 간 불일치 발생 (8/11 기준 1,411 vs 1,422.15) |
| 개별 종목 종가 | 낮음 — 8/10 삼성전자에 230,000 / 231,500 / 232,000 / 234,000 4개 값 혼재 |
| 개별 종목 장중 시세 | 매우 낮음 — 뉴스 색인이 실시간을 따라가지 못함 |
| "2026년 8월 평균 63,732원" 류 전망 | **인용 금지** — 알고리즘 추정치 |

**→ 개별 종목 시세는 증권사 앱이 항상 우선한다.**

## 6. 미해결 과제

### VOO 목표 비중이 산술적으로 도달 불가능하다 (2026-08-11 발견)

| | 현재 | 목표 | 부족분 |
|---|---:|---:|---:|
| SCHD | 19.45% | 35~40% | +$1,228 |
| VOO | **2.32%** | **25~30%** | **+$1,713** |

적립식 $12.5/일을 8종목에 균등 배분하면 SCHD+VOO 몫은 $3.12/일이고,
부족분 $2,941 을 메우는 데 **941일(2.6년)** 이 걸린다.

셋 중 하나를 택해야 한다.

1. **목표 재조정** — VOO 25~30% 를 현 자산 규모에 맞게 10~15% 로 하향
2. **자금 경로 명시** — 미장 전환 2·3단계 정예화 대금을 VOO 에 우선 배정
3. **적립 배분 변경** — 8종목 균등을 SCHD·VOO 가중으로 전환

연말 목표를 20M → 15~17M 로 현실화한 것과 같은 성격의 조정이 필요하다.

`python3 scripts/strategy_check.py --section alloc` 로 현재 격차를 확인할 수 있다.

## 7. 사용법

```bash
# 전체 점검 (계좌·트리거·환율·비중·원칙·이벤트·감시목록)
python3 scripts/strategy_check.py

# 최신 시세를 넣고 트리거만 확인
python3 scripts/strategy_check.py --prices prices.json --fx 1418 --section triggers

# 보유 종목 비중·손익
python3 scripts/portfolio_report.py --market all
```

`prices.json` 은 `{"삼성전자": 231500, "PLTR": 172.15}` 형태로, 국내는 종목명,
해외는 티커를 키로 쓴다.

**매매 후에는 `scripts/portfolio.json` 을 반드시 갱신한다.** 갱신하지 않으면 브리핑이
더 이상 보유하지 않은 종목을 다루게 된다.
